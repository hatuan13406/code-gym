03 KHÁI NIỆM
⇅ 01

Flex Direction

Chọn hướng sắp xếp các thành phần theo hàng hoặc cột.

flex-direction: column;
↔ 02

Flex Grow

Phân chia không gian giữa nội dung chính và sidebar.

content: 3; sidebar: 1;
▧ 03

Flex Wrap

Cho phép các thẻ tự xuống dòng khi màn hình nhỏ hơn.

flex-wrap: wrap;
CẤU TRÚC RESPONSIVE

Bố cục thay đổi như thế nào?

● CSS THUẦN
style.css
.container {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}
.main-container { display: flex; flex: 1; }
.content { flex: 3; }
.sidebar { flex: 1; }

@media (max-width: 768px) {
  .main-container {
    flex-direction: column;
  }
}
✓
Desktop: bố cục 3:1

Nội dung chính chiếm 3 phần, sidebar chiếm 1 phần ở bên phải.

✓
Mobile: xếp theo cột

Khi màn hình nhỏ hơn hoặc bằng 768px, sidebar nằm dưới nội dung.

✓
Không dùng JavaScript

Toàn bộ khả năng responsive được thực hiện bằng Flexbox và Media Queries.
