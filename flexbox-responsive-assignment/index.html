KIẾN THỨC CƠ BẢN

Các thành phần của Flexbox

Học cách sắp xếp giao diện linh hoạt bằng CSS thuần.

03 CHỦ ĐỀ
⇅01

Flex Direction

Quyết định các thành phần nằm theo hàng hay theo cột.

flex-direction: column;
↔02

Flex Grow

Cho nội dung chính chiếm 3 phần và Sidebar chiếm 1 phần.

flex: 3; flex: 1;
▤03

Flex Wrap

Đưa các thẻ xuống dòng tự nhiên khi không đủ chỗ.

flex-wrap: wrap;
RESPONSIVE WEB DESIGN

Cách bố cục tự thích ứng

● CSS THUẦN
style.css
.container {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}
.main-container {
  display: flex;
  flex: 1;
}
.content { flex: 3; }
.sidebar { flex: 1; }

@media (max-width: 768px) {
  .main-container {
    flex-direction: column;
  }
}
