Bố cục trang với float và overflow

Bài thực hành kết hợp hai kỹ thuật CSS cơ bản: float để chia trang thành hai cột và overflow để xử lý văn bản dài trong một khung có kích thước cố định.

VÙNG CUỘN NỘI DUNG

Khi đoạn văn nhiều hơn diện tích hiển thị của khối, thuộc tính overflow: auto sẽ giúp thanh cuộn xuất hiện khi cần thiết. Người dùng có thể cuộn nội dung bên trong ô này mà không làm ô tăng chiều cao. Phần văn bản phía sau vẫn có thể đọc được khi kéo thanh cuộn xuống. 03
CÚ PHÁP CẦN GHI NHỚ

CSS trọng tâm của bài

.container {
    width: 100%;
    overflow: hidden;
}

.left-column  { width: 50%; float: left; }
.right-column { width: 50%; float: right; }

.container::after {
    content: "";
    display: block;
    clear: both;
}

.overflow-box {
    width: 300px;
    height: 100px;
    background-color: lightcoral;
    padding: 10px;
    overflow: auto;
}
