02 / SASS CLI

Các câu lệnh bạn cần nắm.

Mọi lệnh chạy trong Terminal tại thư mục có file package.json.

01

Kiểm tra Node.js và npm

node -v && npm -v

Xác nhận công cụ đã được cài trên máy.

02

Cài Sass cho dự án

npm install

Tải phiên bản Sass được khai báo trong package.json.

03

Biên dịch một file

npm run build:single

Chuyển styles.scss thành styles.css.

04

Watch một file

npm run watch:single

Tự biên dịch lại khi styles.scss thay đổi.

05

Biên dịch cả thư mục

npm run build:all

Chuyển scss/*.scss thành css/*.css; bỏ qua file bắt đầu bằng dấu _.

06

Watch cả thư mục

npm run watch:all

Thay đổi bất kỳ source SCSS liên quan và quan sát kết quả CSS.

package.json · scripts● ● ●
{
  "scripts": {
    "build:single":
      "sass styles.scss styles.css --no-source-map",

    "watch:single":
      "sass --watch styles.scss styles.css --no-source-map",

    "build:all":
      "sass scss/:css/ --no-source-map",

    "watch:all":
      "sass --watch scss/:css/ --no-source-map"
  }
}
Tip: Dùng Ctrl + C để dừng tiến trình --watch.
