KIẾN THỨC CẦN NHỚ

Responsive hoạt động như thế nào?

● LIVE CSS
style.css
.page-grid {
  display: grid;
  grid-template-columns: minmax(0, 3fr) minmax(0, 1fr);
  grid-template-areas:
    "header header"
    "nav nav"
    "main sidebar"
    "footer footer";
}

@media (max-width: 768px) {
  .page-grid {
    grid-template-columns: 1fr;
    grid-template-areas:
      "header"
      "nav"
      "main"
      "sidebar"
      "footer";
  }
}
