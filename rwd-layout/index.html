NỘI DUNG CHÍNH

Chào mừng đến với RWD Studio 👋

Responsive Web Design (RWD) giúp trang web hiển thị hợp lý ở nhiều độ phân giải mà không cần tạo riêng từng phiên bản. Chúng ta dùng Grid chia các vùng lớn, Flexbox căn chỉnh thành phần và Media Queries thay đổi bố cục theo chiều rộng màn hình.
