01 / CSS → SCSS

Giữ nguyên giao diện.
Thay đổi cách tổ chức mã.

Thay những giá trị lặp lại bằng biến và tách trách nhiệm vào các file SCSS riêng.

CSS ban đầustyles.css
.button {
  background: blue;
  color: white;
  padding: 10px 20px;
  border-radius: 5px;
}

.card {
  border: 1px solid #ddd;
  padding: 20px;
  box-shadow: 2px 2px 10px
    rgba(0, 0, 0, 0.1);
}
SCSS đã tổ chức lạicomponents/*.scss
.button {
  @include mix.button-style(
    vars.$primary-color
  );

  &:hover {
    background: #002fbe;
  }
}

.card {
  border: 1px solid
    vars.$border-color;
  padding: 20px;
  @include mix.box-shadow;
}
02 / CÁC KHÁI NIỆM

Ba công cụ mạnh mẽ của Sass.

Cách tổ chức theo module giúp tìm, thay đổi và tái sử dụng mã dễ dàng hơn.

$

Variables

Lưu màu sắc, border và shadow vào một nơi, không phải tìm từng giá trị trong nhiều file.

$primary-color: blue;
{ }

Mixins

Đóng gói nhóm thuộc tính CSS để dùng lại với @include khi cần.

@include mix.box-shadow;
&

Nesting & Partials

Viết selector liên quan cùng nhau và chia code thành các file _*.scss dễ quản lý.

&:hover { ... }

04 / THỰC HÀNH SASS CLI

Biên dịch SCSS trong ba bước.

Chạy các lệnh này trong Terminal tại thư mục dự án chứa package.json.

BƯỚC 01

Cài Sass

Node.js và npm phải được cài trên máy tính.

npm install
BƯỚC 02

Biên dịch CSS

Biên dịch toàn bộ SCSS qua file scss/main.scss.

npm run build
BƯỚC 03

Theo dõi thay đổi

Sass tự tạo lại CSS mỗi khi bạn chỉnh sửa các partials.

npm run watch
