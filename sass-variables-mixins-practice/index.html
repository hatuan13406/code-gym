01 / SASS FUNDAMENTALS

Ít mã lặp lại.
Nhiều giá trị hơn.

Ba kỹ thuật giúp CSS trở nên ngắn gọn, có cấu trúc và dễ bảo trì.

01 / 03$

Variables

Màu sắc, kích thước chữ và khoảng cách đều dùng lại từ một nguồn thống nhất.

$primary-color: red;
02 / 03{ }

Mixins

Gom những thuộc tính thường đi cùng nhau để tránh sao chép nhiều lần.

@include mix.box-style;
03 / 03↗

Partials

Chia code thành Typography, Buttons và Cards để tìm và chỉnh sửa dễ hơn.

@use "components/cards";
02 / CSS → SCSS

Cùng giao diện.
Mã nguồn thông minh hơn.

Giá trị lặp lại được tập trung vào biến và mixin thay vì đặt trực tiếp trong nhiều selector.

CSS ban đầustyles-before.css
.button {
  background: red;
  color: white;
  padding: 10px 20px;
  border-radius: 5px;
}

.card {
  background: white;
  padding: 15px;
  border-radius: 10px;
  box-shadow: 2px 2px 10px
    rgba(0, 0, 0, 0.1);
}
Giá trị được viết trực tiếp trong CSS.
SCSS sau tối ưucomponents/*.scss
.button {
  @include mix.button-style(
    v.$primary-color
  );
}

.card {
  @include mix.box-style;

  &:hover {
    transform: translateY(-4px);
  }
}
Các thuộc tính được tái sử dụng từ mixin.

04 / SASS CLI

Biên dịch SCSS
chỉ với 3 bước.

Chạy các lệnh dưới đây trong Terminal tại thư mục chứa file package.json.

BƯỚC 01

Cài Sass

Đảm bảo có Node.js và npm, sau đó cài Sass vào dự án.

npm install
BƯỚC 02

Biên dịch CSS

Biên dịch scss/main.scss ra css/main.css.

npm run build
BƯỚC 03

Watch Mode

Sửa biến Sass, lưu file và quan sát CSS được cập nhật.

npm run watch
