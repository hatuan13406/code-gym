# [Bài tập] Phân tích và Xây dựng Cấu Trúc Website Template

Bài tập CodeGym gồm **2 nhiệm vụ**:

1. Phân tích một trang web thật: **MDN Web Docs** (https://developer.mozilla.org/en-US/). Bài phân tích nằm ở [PHAN_TICH_WEBSITE.md](PHAN_TICH_WEBSITE.md).
2. Xây dựng website **LearnWeb** bằng **HTML và CSS thuần**, theo bố cục tương tự ở mức đơn giản: Header, Navigation Menu, Content Section, Footer.

## Cấu trúc

```
website-structure-analysis/
├── index.html
├── style.css
├── PHAN_TICH_WEBSITE.md
├── README.md
└── screenshots/
    └── README.md
```

## Tính năng giao diện

- Header có tên website và mô tả.
- Navbar 5 mục: Trang chủ, HTML, CSS, JavaScript, Web APIs.
- Nội dung gồm hero, 4 thẻ công nghệ và phần giải thích bố cục.
- Footer có bản quyền và đường dẫn trang MDN.
- CSS Flexbox, Grid, Spacing, Responsive (desktop/tablet/mobile).
- Không cần JavaScript, ảnh hay CDN; mở offline vẫn được.

## Chạy bài

Mở `index.html` bằng Chrome/Edge hoặc VS Code Live Server. Thử nhấp vào menu và thu nhỏ cửa sổ để kiểm tra responsive.

## QUAN TRỌNG: Ảnh chụp website gốc

**Hiện chưa có ảnh chụp MDN gốc**, vì môi trường không mở được trực tiếp trang này. Xem [screenshots/README.md](screenshots/README.md) để chụp bằng máy của bạn và bổ sung file `screenshots/mdn-original.png` lên GitHub. Đây là yêu cầu nộp bài còn thiếu.
