# Ảnh chụp website gốc

Bài yêu cầu **ảnh chụp màn hình thực tế** trang đã phân tích: https://developer.mozilla.org/en-US/

Ảnh **chưa có trong repository** vì trình duyệt tự động không thể truy cập trang gốc để chụp. Để hoàn thiện nộp bài:

1. Trên máy của bạn, mở https://developer.mozilla.org/en-US/ bằng Chrome hoặc Edge.
2. Đặt cửa sổ đủ rộng để thấy header/menu và các nhóm nội dung.
3. Nhấn **Win + Shift + S** để chụp. Lưu file tên **mdn-original.png**.
4. Trên GitHub, mở thư mục này và chọn **Add file → Upload files**, tải `mdn-original.png` lên, sau đó Commit changes.
5. Kiểm tra hình mở được từ GitHub trước khi nộp bài.

Không dùng ảnh của trang LearnWeb làm ảnh chụp MDN. Đề yêu cầu ảnh **trang web gốc**.
