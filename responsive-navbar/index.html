CƠ CHẾ HOẠT ĐỘNG

Một thanh điều hướng, mọi kích thước màn hình

Kết hợp các kỹ thuật cơ bản để website hoạt động mượt mà trên desktop và mobile.

01▦

Flexbox trên desktop

Thuộc tính display: flex sắp xếp logo và các liên kết cùng một hàng ngang, dễ dàng căn chỉnh khoảng cách.

display: flex
02▣

Media Queries trên mobile

Với màn hình ≤ 768px, danh sách liên kết được ẩn đi và nút menu ☰ xuất hiện để tiết kiệm không gian.

max-width: 768px
03✳

JavaScript mở / đóng

Khi nhấn biểu tượng ☰, JavaScript thêm hoặc xóa class active để điều khiển trạng thái của menu.

classList.toggle()
↔

Hãy thử thu nhỏ cửa sổ trình duyệt!

Khi chiều rộng nhỏ hơn hoặc bằng 768px, thanh điều hướng phía trên sẽ hiển thị nút ☰. Nhấn để mở hoặc đóng danh sách liên kết. Nhấn phím Esc hoặc chạm ra ngoài để đóng menu.
