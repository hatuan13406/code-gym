# [Thực hành] Quản lý nội dung bị tràn với Overflow

Bài thực hành HTML/CSS minh họa `overflow: auto` cho một khối nội dung **rộng 300px, cao 100px**, nền `lightgray`, padding `10px`.

## Chạy bài

1. Mở `index.html` trong Chrome hoặc Edge (hoặc VS Code Live Server).
2. Kéo thanh cuộn **bên trong khung màu xám** để xem tiếp nội dung mà không làm tăng chiều cao khối.
3. Có thể kiểm tra bằng DevTools: `.overflow-box` có `overflow: auto`, `scrollHeight > clientHeight`.

## Tệp bài làm

- `index.html`: cấu trúc và văn bản dài.
- `style.css`: bố cục, CSS, phần chính `.overflow-box`.
- Ảnh kết quả `ket-qua-overflow.png` cung cấp riêng để nộp CodeGym.

**Lưu ý:** CodeGym yêu cầu **nộp ảnh**, vì vậy hãy tải file PNG và nộp trực tiếp, thay vì chỉ dán link GitHub.
