# Thực hành sử dụng CSS

Bài thực hành luyện tập các thuộc tính CSS cơ bản.

## Nội dung đã thực hiện

- Đổi màu chữ bằng `color`
- Thay đổi font bằng `font-family`
- Thay đổi kích thước chữ bằng `font-size`
- Tạo đường viền bằng `border`
- Tạo khoảng cách bên trong bằng `padding`
- Sử dụng bộ chọn ID với `#element1`
