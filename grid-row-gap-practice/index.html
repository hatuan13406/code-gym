GIÁ TRỊ TOÀN CỤC · GLOBAL VALUES

initial · inherit · unset · revert

So sánh 4 giá trị toàn cục. Khối cha của từng Grid được đặt row-gap: 28px để thấy rõ hiệu ứng kế thừa.

initial

grid-row-gap: initial;

Trở về giá trị mặc định: normal (khoảng cách thực tế: 0px trong CSS Grid).
