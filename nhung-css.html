Phần 1: Tiêu đề (Inline Style)

Đây là đoạn văn được đổi màu bằng Inline-style. CSS được viết trực tiếp vào bên trong thẻ mở của HTML.

Phần 2: Tiêu đề (Internal Style)

Đây là đoạn văn được đổi màu bằng Internal-style. CSS được quy định trong thẻ <style> ở phần đầu trang web.

Phần 3: Tiêu đề (External Style)

Đây là đoạn văn được đổi màu bằng External-style. CSS được tải vào từ file style.css riêng biệt.
