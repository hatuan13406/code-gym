Làm chủ Bootstrap Grid System

Bootstrap chia chiều rộng mỗi hàng thành 12 phần. Chỉ cần kết hợp class cột, bố cục sẽ thay đổi theo kích thước màn hình mà không cần tự viết hệ thống lưới từ đầu.

Các kỹ thuật được sử dụng

▧

Bootstrap Container

Giới hạn chiều rộng và căn giữa nội dung bằng .container.

class="container"
▦

Bootstrap Grid

Dùng .row và các cột .col-lg-* để chia tỉ lệ.

col-12 col-lg-8
☰

Navbar & Dropdown

Menu có nút mở trên điện thoại và menu con Bootstrap.

navbar-expand-lg
⇲

Responsive Layout

Hai cột trên desktop; chuyển thành một cột khi dưới 992px.

col-12 col-lg-4

Cấu trúc HTML quan trọng

GRID 12 CỘT 
<div class="container">
  <div class="row g-4">
    <main class="col-12 col-lg-8">
      Main Content
    </main>
    <aside class="col-12 col-lg-4">
      Sidebar
    </aside>
  </div>
</div>

Lưu ý: col-lg-* đổi thành hai cột ở ≥992px. Dùng col-md-* sẽ đổi bố cục ngay từ 768px, không khớp breakpoint desktop trong đề.

THANH BÊN

Góc thông tin

Trên desktop, Sidebar nằm bên phải. Trên màn hình dưới 992px, Sidebar chuyển xuống bên dưới nội dung chính.
