Thực hành qua 5 ví dụ

Mỗi ví dụ thể hiện một cách sử dụng flex-basis khác nhau.

05 DEMOS
01
VÍ DỤ 1 · LENGTH

Thiết lập kích thước bằng px

Ba ô có kích thước cơ sở lần lượt 200px, 100px và 150px.

MAIN AXIS →
PREVIEW / FLEX-DIRECTION: ROWgap: 10px
Item 1200px
Item 2100px
Item 3150px
ⓘ

flex: 0 0 ... giữ đúng kích thước cơ sở trong ví dụ này bằng cách tắt grow và shrink. Với box-sizing: border-box, kích thước đã bao gồm padding.

.item1 { flex-basis: 200px; }  .item2 { flex-basis: 100px; }  .item3 { flex-basis: 150px; }
02
VÍ DỤ 2 · MAIN AXIS

Thay đổi trục với flex-direction: column

Khi hướng Flex là column, flex-basis: 100px đặt kích thước theo chiều cao.

MAIN AXIS ↓
PREVIEW / FLEX-DIRECTION: COLUMNheight: 350px
Item 1100px cao
Item 2100px cao
Item 3100px cao
ⓘ

flex-direction: row → cơ sở theo chiều ngang. flex-direction: column → cơ sở theo chiều dọc. Ba ô cao 100px và cách nhau 10px.

.container { display: flex; flex-direction: column; height: 350px; gap: 10px; }
.item { flex-basis: 100px; flex-shrink: 0; }
03
VÍ DỤ 3 · PERCENTAGE

Kích thước cơ sở với 50%

Hai ô cùng có cơ sở bằng 50% chiều rộng của Flex Container.

MAIN AXIS →
PREVIEW / 2 ITEMSflex-basis: 50%
Item 150% basis
Item 250% basis
ⓘ

Hai cơ sở 50% cộng với gap: 10px vượt quá không gian container. Vì flex-shrink: 1, trình duyệt co mỗi ô lại để vừa một hàng.

.container { display: flex; gap: 10px; }
.item { flex-basis: 50%; flex-shrink: 1; box-sizing: border-box; }
04
VÍ DỤ 4 · FLEX-GROW

Phân phối không gian với flex-grow

Mỗi ô bắt đầu từ 100px, sau đó phần không gian còn trống chia theo tỷ lệ 1 : 2 : 1.

MAIN AXIS →
PREVIEW / CONTAINER 600pxgrow: 1 : 2 : 1
Item 1grow: 1
Item 2grow: 2
Item 3grow: 1
ⓘ

Không gian dư: 600 − (3 × 100) − (2 × 10) = 280px. Ba ô nhận thêm 70px / 140px / 70px, tạo chiều rộng thực tế 170px / 240px / 170px.

.item1 { flex-basis: 100px; flex-grow: 1; }
.item2 { flex-basis: 100px; flex-grow: 2; }
.item3 { flex-basis: 100px; flex-grow: 1; }
05
VÍ DỤ BỔ SUNG · KEYWORDS

So sánh auto, initial, inherit

Cả ba từ khóa đều có giá trị sử dụng riêng. Ví dụ được thiết kế để nhìn thấy kết quả trực tiếp.

CSS GLOBAL
PREVIEW / GIÁ TRỊ TỪ KHÓAflex-shrink: 0
autowidth: 140px
initialwidth: 140px
inherit180px từ cha
ⓘ

auto dựa vào width: 140px và initial trở về auto. Với inherit, ô thứ ba nhận flex-basis: 180px từ phần tử cha; giá trị này được đặt rõ ràng trên cha chỉ để minh họa sự kế thừa.

.parent { display: flex; flex-basis: 180px; }
.auto { width: 140px; flex-basis: auto; }
.initial { width: 140px; flex-basis: initial; }
.inherit { flex-basis: inherit; }
✦

Ghi nhớ

flex-basis là kích thước cơ sở theo trục chính, chưa chắc là kích thước cuối cùng: flex-grow có thể tăng và flex-shrink có thể giảm kích thước đó.
